# Delivery Cancellation & Logistics Analysis

An end-to-end data analysis and machine learning project predicting order delivery cancellations, designed to optimize logistics performance.

## 🚀 Project Overview
In e-commerce logistics, high cancellation rates cost both time and revenue. This project analyzes delivery operational datasets, cleans and structures data, uncovers key patterns, and applies Machine Learning models using **Scikit-Learn** to predict delivery cancellations before they happen.

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Environment:** Jupyter Notebook, VS Code, Mac Bash
* **Data Manipulation & Analysis:** Pandas, NumPy
* **Machine Learning:** Scikit-Learn
* **Version Control:** Git & GitHub

## 📊 Key Steps & Methodology
1. **Data Cleaning & Preprocessing:** Handled missing values, normalized features, and prepared structured datasets for modeling.
2. **Exploratory Data Analysis (EDA):** Visualized feature correlations and distribution patterns impacting order fulfillment.
3. **Machine Learning Modeling:** Implemented classification models to forecast order cancellations with evaluation metrics.
